# AI 업무 비서

대화하면서 일을 시키는 개인 비서입니다. **무료 API만 쓰고, 설치할 것도 없습니다.**

```
나 ▸ 오늘 온 메일 정리해줘
   🔧 read_mail(hours=24)
      → 최근 24시간 메일 14통

🤖 14통 중 처리가 필요한 건 5건입니다.

   1. [A사 / 김과장] 계약 조건 변경 검토 — 내일까지 회신 요청
   2. [운영팀] CCX 현행화 요청 — 대상 3건 명시됨
   3. [회계] 8월 경비 정산 마감 안내 — 9/12까지
   ...
   나머지 9통은 공지·뉴스레터입니다.

나 ▸ 그럼 CCX 현행화는 자동화 스크립트로 처리해줘
   🔧 ccx_현행화(target=전체)

──────────────────────────────────────────
⚠️  실행 확인이 필요합니다
   도구  : ccx_현행화  (commands.json)
   내용  : 실행: python \\서버\ccx\update.py --target {target}
   target: 전체
──────────────────────────────────────────
실행할까요? [y/N] y
      → 종료 코드: 0

🤖 현행화 완료했습니다. 대상 3건 모두 처리됐습니다.
```

---

## 핵심 아이디어

무료 모델은 판단력이 약합니다. 그래서 **비서가 똑똑해지길 기대하지 않고, 도구를 쌓아서 강해지게** 만들었습니다.

```
         ┌──────────────────────────────┐
         │  비서 (Gemini, 무료)          │
         │                              │
         │  · 대화하고 도구를 고른다      │
         │  · 못 하면 솔직히 말한다       │
         └───────────┬──────────────────┘
                     │
      ┌──────────────┼──────────────┐
      ▼              ▼              ▼
   메일 읽기     등록한 스크립트   "못 하겠습니다"
   (IMAP)       (commands.json)   → 요청서 자동 생성
                                        │
                                        ▼
                            다른 AI(Claude Code 등)로 해결
                                        │
                                        ▼
                        결과를 도구/문서로 넣어줌 ──┐
                                                   │
      ◀────────────────────────────────────────────┘
             다음부터는 비서가 알아서 함
```

비서가 못 하는 일을 만나면 지어내지 않고 **요청서를 만들어 줍니다.** 그걸 Claude Code 같은 데 붙여넣어 해결한 뒤 결과를 넣어주면, 그때부터 비서가 그 일을 할 수 있습니다. 쓸수록 할 수 있는 일이 늘어납니다.

## 설치 (5분)

### 1. 폴더를 통째로 복사

**설치할 게 없습니다.** 파이썬 3.10 이상만 있으면 됩니다. pip 도 필요 없습니다 (표준 라이브러리만 씁니다). 사내 PC에서 pip 가 막혀 있어도 돌아갑니다.

파이썬이 있는지 확인:

```bash
python --version
```

없으면 [python.org](https://www.python.org/downloads/) 에서 설치할 때 **"Add Python to PATH"** 를 꼭 체크하세요.

### 2. API 키 발급 (무료, 1분)

[aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에서 **Create API key**. 카드 등록 필요 없습니다.

### 3. .env 만들기

`.env.example` 을 복사해 이름을 `.env` 로 바꾸고, 메모장으로 열어 키를 넣으세요.

```
GEMINI_API_KEY=여기에_받은_키
```

메일 기능을 쓰려면 `IMAP_USER`, `IMAP_PASS` 도 채웁니다. 안 쓸 거면 비워두세요 — 나머지는 그대로 동작합니다.

메일 서버 주소는 `config.json` 의 `mail` 에 있습니다. 회사마다 다릅니다.

| 메일 | 방식 | 주소 | 포트 |
|---|---|---|---|
| 하이웍스 | **POP3만** | `pop3s.hiworks.com` | 995 (SSL) |
| Gmail | IMAP | `imap.gmail.com` | 993 (앱 비밀번호 필요) |
| 네이버 | IMAP | `imap.naver.com` | 993 |
| Office365 | IMAP | `outlook.office365.com` | 993 |

**하이웍스는 IMAP 을 제공하지 않습니다.** POP3 로 붙어야 하고, 쓰기 전에 웹메일에서 두 가지를 해둬야 합니다.

1. `[메일 > 환경설정 > 기본 설정]` 에서 **POP3 사용**을 켭니다.
2. `[보안 설정]` 에서 **메일 전용 비밀번호**를 따로 만듭니다. 하이웍스 로그인 비밀번호로는 POP3 로그인이 안 됩니다. 이 전용 비밀번호를 `.env` 의 `IMAP_PASS` 에 넣으세요.

POP3 는 폴더도 안읽음 표시도 없어서 받은편지함만 최근 것부터 읽습니다. 나머지는 IMAP 과 똑같이 동작합니다.

주소를 모르겠으면 `IMAP_USER` / `IMAP_PASS` 만 채우고 `python assistant.py 진단` 을 돌리세요 — IMAP·POP3 후보를 차례로 시도해보고 되는 쪽을 알려줍니다.

### 4. 점검

```bash
python assistant.py 진단
```

Gemini 연결 · 도구 호출 · 메일 · 도구 등록을 순서대로 확인하고, 안 되는 게 있으면 무엇을 고쳐야 하는지 알려줍니다. 모델 이름이 틀렸으면 **쓸 수 있는 모델 목록**을 보여줍니다.

### 5. 시작

```bash
python assistant.py
```

## 쓰는 법

그냥 하고 싶은 말을 쓰면 됩니다.

| 이렇게 쓰면 | 비서가 하는 일 |
|---|---|
| `오늘 온 메일 정리해줘` | 메일을 읽어서 처리 필요한 것만 추려 보고 |
| `CCX 관련 메일 있어?` | 키워드로 메일 검색 |
| `3번 메일 전문 보여줘` | 그 메일만 전체 본문 확인 |
| `그럼 현행화는 스크립트로 처리해줘` | 등록된 스크립트 실행 (확인 후) |
| `A사 담당은 김과장이야, 기억해` | 기억에 저장 — 다음부터 안 물어봄 |
| `CCX 절차 정리해서 저장해둬` | 문서로 저장, 나중에 꺼내 씀 |
| `뭘 할 수 있어?` | 지금 가진 도구 목록 |

대화 중 슬래시 명령:

```
/도구      쓸 수 있는 도구 목록
/기억      저장된 기억 보기
/문서      보관 중인 문서 목록
/새대화    대화 맥락 지우기 (기억·문서는 남음)
/도움말    사용법
/종료      끝내기
```

한 번만 물어보고 끝내려면:

```bash
python assistant.py "오늘 온 메일 정리해줘"
```

## 비서에게 능력을 추가하는 법

여기가 이 시스템의 전부입니다. 두 가지 방법이 있습니다.

> 도구 이름은 **영문**으로 지으세요 (`mail_cleanup` ○ / `메일정리` ✗). Gemini 가 한글 함수 이름을 거절해서, 하나라도 섞이면 대화 전체가 400 오류로 막힙니다. 진단이 잡아내서 알려줍니다.

### 방법 1 — commands.json 에 명령 등록 (파이썬 몰라도 됨)

이미 있는 스크립트나 실행 파일을 등록하면 끝입니다.

```json
{
  "ccx_현행화": {
    "description": "CCX 현행화 자동화 스크립트를 실행한다. 메일에 CCX 현행화 요청이 있거나 사용자가 현행화를 지시했을 때 쓴다.",
    "argv": ["python", "\\\\서버\\공유폴더\\ccx\\update.py", "--target", "{target}"],
    "parameters": {
      "type": "object",
      "properties": {
        "target": { "type": "string", "description": "현행화 대상. 비우면 전체" }
      },
      "required": []
    },
    "confirm": true,
    "timeout_sec": 1800
  }
}
```

- **`description` 이 제일 중요합니다.** 비서는 이 설명만 읽고 언제 쓸지 정합니다. "언제 쓰는 도구인지"를 사용자가 할 법한 말과 함께 적으세요.
- `argv` 는 명령을 **조각으로 나눠** 적습니다. `{인자}` 자리에 값이 들어갑니다. 셸을 거치지 않아서 값에 따옴표나 특수문자가 들어가도 안전합니다.
- `confirm` 은 **기본값이 `true`** 입니다. 되돌리기 어려운 작업은 그대로 두세요.

`commands.json` 에 이미 예시 두 개가 `_꺼둠_` 이름으로 들어 있습니다. 이름에서 `_꺼둠_` 을 떼고 경로만 바꾸면 바로 쓸 수 있습니다.

### 방법 2 — tools/ 폴더에 파이썬 파일 추가

더 복잡한 일은 파이썬으로. `tools/_템플릿.py` 를 복사해서 고치세요.

```python
from core.registry import tool

@tool(
    name="도구이름",
    description="언제 쓰는 도구인지",
    parameters={
        "type": "object",
        "properties": {"인자": {"type": "string", "description": "설명"}},
        "required": [],
    },
    confirm=False,
)
def 함수(인자: str = "") -> str:
    return "결과 문자열"
```

파일을 넣기만 하면 다음 실행 때 자동으로 잡힙니다.

### 방법 3 — 지식만 넣어주기

스크립트가 아니라 **알고만 있으면 되는 것**은 `data/notes/` 에 `.md` 파일로 넣으세요. 절차서, 조사 결과, 사내 용어집 같은 것들요.

비서는 파일 목록을 항상 알고 있다가 필요할 때 꺼내 읽습니다. **다른 AI로 정리한 내용을 여기에 넣어주면 그게 곧 비서의 지식이 됩니다.**

## 비서가 못 하겠다고 할 때

이게 정상 동작입니다. 이럴 때 이런 게 나옵니다.

```
🤖 이건 지금 제가 가진 도구로는 못 합니다.

   필요한 것:
   다른 서버의 ccx update.py 를 실행할 수 있는 명령 등록

   다른 AI 에 붙여넣을 요청서를 만들어 뒀습니다:
     data/requests/20260908-2301-CCX-현행화-자동-실행.md
```

그 파일을 열면 **Claude Code 같은 데 그대로 붙여넣을 수 있는 요청서**가 들어 있습니다. 이 비서의 도구 규격과 지금 가진 도구 목록까지 포함돼 있어서, 받는 쪽이 바로 맞는 형태로 만들어 줍니다.

만들어진 걸 `commands.json` 이나 `tools/` 에 넣으면 다음부터는 비서가 처리합니다.

## 무료 API 한도

Gemini 무료 티어 기준 (2026년 9월):

| | 한도 |
|---|---|
| 분당 요청 | 10회 |
| 하루 요청 | 1,500회 |
| 분당 토큰 | 250,000 |
| 컨텍스트 | 1M |

개인이 쓰기엔 넉넉합니다. 한 대화에 도구를 여러 번 부르면 요청도 여러 번 나가니, 분당 10회는 연달아 빠르게 물어보면 걸릴 수 있습니다. 그럴 땐 잠깐 기다렸다 다시 하면 됩니다 (비서가 자동으로 두 번 재시도합니다).

Pro 모델은 2026년 4월에 무료 티어에서 빠져서 Flash 계열만 씁니다. 모델을 바꾸려면 `config.json` 의 `model.id` 를 고치세요. 어떤 게 되는지는 `python assistant.py 진단` 이 알려줍니다.

`503 (high demand)` 은 그 모델에 사람이 몰렸다는 뜻이지 설정이 틀린 게 아닙니다. `config.json` 의 `model.fallbacks` 에 적어둔 모델로 비서가 알아서 바꿔 시도합니다.

  llm.py             Gemini 호출 (interactions / generateContent 양쪽 지원)
  agent.py           대화 루프 — 모델 ↔ 도구 왕복
  registry.py        도구 수집·실행

## 알아둘 점

- **비서 말을 무조건 믿지 마세요.** 메일 내용은 도구로 실제 읽은 것만 말하게 해뒀지만, 무료 모델은 요약 과정에서 뉘앙스를 놓칠 수 있습니다. 중요한 건 `3번 메일 전문 보여줘` 로 원문을 확인하세요.
- **`confirm: true` 를 함부로 끄지 마세요.** 스크립트 실행은 되돌리기 어렵습니다. 확인 절차가 유일한 안전장치입니다.
- **`.env` 와 `data/` 는 공유하지 마세요.** 회사 메일 내용이 `data/` 에 남습니다. `.gitignore` 에 이미 들어 있습니다.
- **메일은 읽기 전용입니다.** 읽음 처리나 삭제를 하지 않습니다.
- 이전에 만들었던 일정 스케줄러는 `바탕 화면/일정_백업_스케줄러/` 에 그대로 있습니다. 필요 없으면 지우세요.
